# kkps-d.github.io

Portforlio site   
Made with create-react-app, and then ported to Vite.js with React Router to make an single page app.   
SPA is made to work with GitHub Pages thanks to [this guide](https://github.com/rafgraph/spa-github-pages).

The About Me introduction, current role, location, education, contact details,
and Gradiotronics overview were updated from `../public/Kaung Khant Pyae Sone CV 2026.docx`.
The introduction uses its Summary Statement verbatim. The resume viewer serves
the matching 2026 PDF from `public/`. Other project descriptions retain the
original portfolio text.

Run `npm ci` and `npm run build` from this directory to build the archived site.
